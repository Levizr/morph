# Sponsor Morph

Morph is free, open-source, and built by [Levizr Technologies](https://www.levizr.com) — a small, independent team. There is no company funding behind it. Your support keeps Morph fast, tiny, and free.

## How to support

**Donate — one link (international + India):**

👉 **https://morph.levizr.com/sponsor**

Every amount helps — server costs, test devices, and full-time work on the compiler, renderer, and docs.

**Not about money? You can also:**

1. Star the repo and share what you built with Morph
2. Fix a bug or improve the [docs](docs/) — typo fixes count
3. Report bugs with a minimal `.mx` repro — a found bug is half-fixed
4. Build an example app under `examples/` so others learn faster

See [CONTRIBUTING.md](CONTRIBUTING.md) for code setup (`cargo build --workspace`, `target/debug/morph doctor`).

## Where your support goes

| Area | What it funds |
|---|---|
| Compiler (`morphc`, `morpher`) | TS→C++ coverage, faster builds, better errors |
| Runtime (`runtime/cpp`) | Layout, text, animations, Forge renderer |
| Docs & examples | Tutorials, guides, sample apps |
| Infra | CI runners, test machines (Linux/macOS/Windows), `morph.levizr.com` hosting |
