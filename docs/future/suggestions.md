# Suggestions

**Status:** future · **Priority:** — (you decide)

Got an idea for Morph? A feature you need, a workflow that's painful, a use case we haven't thought of? We want to hear it — **Morph is shaped by the apps people actually build with it.**

The roadmap above is a plan, not a wall. Real-world needs get priority; whole pages have been added from a single suggestion (accessibility, signing, graphics backends all started as "wouldn't it be cool if…").

## How to suggest

- **Email us:** [`suggestions.morph@levizr.com`](mailto:suggestions.morph@levizr.com) — the simplest route. One paragraph is enough: *what you're building, what's missing, and what you tried instead.*
- **Open an issue / PR:** the repo lives at [github.com/Levizr/morph](https://github.com/Levizr/morph) — see [Contributing](../../CONTRIBUTING.md)
- **Contribute** — if you're up for it, code is welcome. Morph is Python + C++ with a tree-sitter compiler; a working patch on an issue beats a hundred wishlist emails. Start with the `good first issue` label
- **Just talk about it** — even a half-formed idea is useful. Describe the pain; we'll figure out the shape.

## What happens next

1. **Acknowledged** — we reply, usually within a few days
2. **Tracked** — it becomes an issue on the repo, tagged `suggestion`
3. **Evaluated** — fits the architecture + real demand? It lands on the roadmap and gets its own page in `docs/future/`
4. **Built** — ideas that make it are documented here before they're implemented, so the design gets reviewed in the open

> **Note:** Suggestions are not commitments. Getting a feature on the roadmap means it's seriously considered — not that it's promised or scheduled.

## Suggested so far

Tracked suggestions live in the repo's issue tracker under the `suggestion` label. High-signal themes that keep coming up:

- **Signing & commercial distribution** — see [Signing & Secure Distribution](security.md)

If one of those is *your* use case, email us and say so — real demand is what moves something up the priority list.
